CUBE WORLD — GitHub #107 (feat: cube world — replace flat terrain play space)
Branch pickup doc — last updated: 2026-05-15
================================================================================

SUMMARY
  Replace the flat-plane mental model with a cube play space: gravity/movement on
  faces, enemies on the same surface, minimap TBD, no silent void falls.

  Today the game is still world +Y up. Standard Assets FirstPersonController uses
  Vector3.down / Physics.gravity. Enemies use transform.forward (no NavMesh).
  MinimapRadar projects XZ only (EnemyGenerator.TryGetArenaBoundsXZ).

WHAT APPLY (Phase 1) DOES
  · Sizes CubeWorld root to terrain footprint; builds GeoCubeVisual + CubePhysics
  · Aligns terrain base on cube top (cube top slightly below terrain to avoid z-fight)
  · Snaps spawn points + player Y to terrain height
  · Re-wires EnemyGenerator spawn arrays from scene objects
  · Disables legacy "Invisible Wall*" objects
  · Clears EdgeWalls / EdgeKillZones children if present; destroys ArenaEdgeKillZone
